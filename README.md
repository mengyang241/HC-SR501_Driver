# HC-SR501 STM32 人体红外传感器驱动

> 我也是刚开始学 STM32 的新手，这份驱动是一边学一边写的，注释尽量详细，
> 希望能帮到和我处于同一阶段的朋友——有问题欢迎指正、交流。

基于 HAL 库的 HC-SR501 人体红外（PIR，被动红外）传感器驱动，适用于 STM32F1 系列。
HC-SR501 检测到人体移动时，OUT 引脚输出高电平；没有人时为低电平，
所以本质就是"读一个 GPIO 的高低电平"，非常简单。

## 特点

- 纯 HAL 实现，轮询读取，不依赖中断
- 引脚可任意指定（`hcsr.port` / `hcsr.pin` 两个字段），GPIOA/B/C 时钟自动打开，
  不需要在 CubeMX 里配置
- 内置 10ms 心跳调度（`HCSR501_proc`），每 100ms 采样一次，够快又不占 CPU
- 文件头注释为英文，含接线、调节和使用说明，与 DHT11 驱动同一风格

## 硬件接线

| HC-SR501 | 接到 STM32                  | 说明 |
|----------|-----------------------------|------|
| VCC      | 3.3V 或 5V                  | 模块标称 4.5~20V，一般接 5V |
| GND      | GND                         | 必须与单片机共地 |
| OUT      | 任意 GPIO（如 PB0 / PB12）  | 用下面的 `hcsr.port` / `hcsr.pin` 指定 |

OUT 电平含义：

- 高电平（读到 1）= 检测到人体移动
- 低电平（读到 0）= 没人 / 无人移动

## 模块上的调节（背面）

| 调钮 | 作用 |
|------|------|
| Sx（灵敏度/距离） | 调节感应距离，约 3~7 米 |
| Tx（延时） | 检测到人后，OUT 保持高电平的时间 |
| 跳线帽 H / L | H = 可重复触发（人持续活动就一直输出高）；L = 不可重复触发 |

## 使用注意

1. 上电后需预热约 30~60 秒，期间输出不稳定（正常现象）
2. 热源 / 太阳光 / 风吹都会造成误触发，安装时避开
3. 传感器检测的是"移动的人"，人静止不动可能不会触发

## 使用方法

```c
/* 告诉驱动 HC-SR501 的 OUT 接在哪根脚 */
hcsr.port = GPIOB;          // 例：OUT -> PB0
hcsr.pin  = GPIO_PIN_0;
HCSR501_Init(&hcsr);        // 把该引脚配置成下拉输入

while (1) {
    HCSR501_proc(&hcsr);    // 每 10ms 一次心跳，内部每 100ms 刷新 hcsr.value
    if (hcsr.value == 1) {  // 检测到人！
        // 开灯、报警、拍照……
    }
}
```

- 引脚随意换：改 `hcsr.port` / `hcsr.pin` 两个字段即可，`HCSR501_Init()` 会自动开对应端口时钟
- 引脚**不用**在 CubeMX 里配置，驱动全包了
- 人走开后，OUT 可能还会保持高电平一小段时间，这是模块 Tx 延时所致，属正常现象

## 结构体字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `value` | `uint8_t` | 最新检测结果：1 = 有人 / 0 = 没人（由 `HCSR501_proc` 自动刷新） |
| `port` | `GPIO_TypeDef*` | OUT 引脚所在端口，如 `GPIOB` |
| `pin` | `uint16_t` | OUT 引脚编号，如 `GPIO_PIN_0` |
| `HUMAN_t` | `uint8_t` | 内部节拍计数器（凑 100ms 用），主程序不用管 |

## 常见问题

**板载 LED 不亮？**
- 如果 LED 是当"检测到人"的指示灯用，那它只在检测到人时才亮，不是电源灯
- 先检查 `hcsr.pin` 是否和实物接线一致：OUT 插在哪个脚，代码里就填哪个脚
- 再检查 VCC 是否接 5V、GND 是否共地；上电预热 30~60 秒后再挥手测试
- 想快速定位：让 LED 开机先闪几下（自检），能闪说明 LED 和引脚正常，
  问题就出在传感器/接线；不闪说明 LED 引脚或板子本身有问题
